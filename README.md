# 🎬 Netflix_Data_Project_Analytics
End-to-end exploratory data analysis (EDA) of Netflix movies and TV shows using Python, SQL, and Power BI. Uncovers content distribution, genre trends, release patterns, and country-wise streaming insights through interactive dashboards.

## 📌 Overview
This project presents an end-to-end Exploratory Data Analysis (EDA) and business intelligence solution for Netflix's content catalog. The goal is to clean raw streaming data, run analytical SQL queries, and build an interactive Power BI dashboard to uncover insights into content distribution (Movies vs. TV Shows), genre trends, release patterns, and country-wise performance.

# 🚀 How to Run

Follow these steps to explore the project:

**Step 1: Clone the Repository**

git clone https://github.com/Deva11-mahadev/Netflix_Data_Project_Analytics.git

   cd Netflix_Data_Project_Analytics

**Step 2: Open and run the Python Notebook**

* Open Netflix data.ipynb in Jupyter Notebook.
* This file covers:
   * Data Import & Inspection (info(), describe())
   * Data Cleaning & Handling Missing Values
   * Feature Engineering and exploratory data analysis.
 
**Step 3: Load Data into SQL Database**

* Import Netflix_Clean_Project.csv into your SQL database (MySQL / PostgreSQL / SQL Server).

* Execute the queries provided in Netflix Customer.sql.

**Step 4: Explore the Power BI Dashboard**

* Open Netflix Data Analysis Project.pbix in Power BI Desktop to explore the visuals and filters.

**Step 5:Review Report & Presentation**

 * Refer to the Netflix Customer & Content Data Analysis.pdf for a detailed summary of findings and strategic business recommendations.
 * Build presentation deck using Canva.
